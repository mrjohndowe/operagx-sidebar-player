# Adult Video Sidebar GX v1.6

Custom Opera GX sidebar extension. Includes your own sidebar panel, quick buttons for Pornhub/XVideos/XFree/XXXFollow, address bar, navigation history, and Open Tab fallback.

## Install
1. Extract ZIP.
2. Open Opera GX `opera://extensions`.
3. Enable Developer Mode and select **Load unpacked**.
4. Choose this folder and pin/open the sidebar icon.

## Important browser limitation
Opera GX sidebar extensions render their panel as an extension HTML document. This extension attempts an iframe for inline site display. Sites may block iframe embedding using CSP or X-Frame-Options. If a site blocks it, use **OPEN TAB ↗**. An extension cannot host a separate unrestricted Chromium browser engine inside GX's sidebar.
